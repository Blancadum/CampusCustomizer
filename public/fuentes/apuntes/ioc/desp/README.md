# 🌐 0614 · Desplegament d'Aplicacions Web (DESP) — IOC DAW

Pilar de contenidos teóricos estructurados para la asignatura de Despliegue de Aplicaciones Web.

## 📋 Estructura Planificada
- **Tema 1: Servidores Web & Nombres de Dominio (DNS)**
  - Apache HTTP Server y Nginx: instalación, configuración y virtual hosts.
  - Registro de dominios, zonas DNS y resolución de nombres.
- **Tema 2: Protocolo HTTP, HTTPS y Certificados SSL/TLS**
  - Métodos, cabeceras, códigos de estado y depuración.
  - Generación de claves, CSR, Let's Encrypt y configuración HTTPS.
- **Tema 3: Servidores de Aplicación & Contenedores Docker**
  - Servidores Java (Tomcat), PHP (PHP-FPM, Apache mod_php), Node.
  - Dockerfiles, imágenes y Docker Compose para servicios web.
- **Tema 4: Seguridad & Monitorización**
  - Firewalls (UFW, iptables), control de accesos y logs.
